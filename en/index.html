ALPR · Multi-camera plate recognition LICENSE PLATE · YOLO

License plate detection pipeline over simultaneous RTSP streams from multiple cameras, with centralized GPU inference

Redesign and development of a plate recognition pipeline: from multi-camera stream ingestion to character detection, result stabilization across consecutive frames and duplicate-free alerting.

  • Multiprocessing and Multithreading architecture for concurrent RTSP ingestion; camera count configured from a JSON file
  • A central GPU Inference process that loads the YOLO model once and serves every camera
  • Inter-process frame transfer with Shared Memory and a lock-free Seqlock-based buffer
  • Plate Stabilizer with IoU Tracking and Majority Voting, with an independent buffer per vehicle
  • A dedicated character detector, a fix for plates containing the Persian letter “Alef”, and alert Deduplication with Redis (1-hour TTL)
  • Benchmarked processing layouts from 1 process × 30 threads to 6 processes × 5 threads
